# Claude 提供商模板

版本：0.5.0-dev；日期：2026-10-09。在 0.4.0 的单文件配置编辑基础上，增加设备本地的多提供商模板库。

## 已实现的操作

- 新增模板：保存名称、认证方式、端点、默认模型及独立密钥。
- 编辑模板：留空密钥只保留该模板自己的同类密钥；切换认证方式时需要输入对应凭据。
- 从当前文件保存：在原生侧复制当前用户级配置的四个受管字段，不包含页面未保存草稿，不将已有密钥返回给 React。
- 预览应用：复用已有原文补丁与加密备份流程，确认后写入 `~/.claude/settings.json`；保留其他 env、hooks、permissions 等内容。
- 删除模板：只删除模板库中的记录，当前配置文件、原生登录和会话保持不变。
- 内容匹配：原生侧比较四个受管字段，包括密钥；匹配时显示“与当前用户配置一致”。这是读取时的用户级配置比较，不代表当前会话或项目实际生效状态。内容相同的多个模板都可以匹配。

模板管理入口复用现有 React / Tailwind 的 ListGroup、BottomSheet、Dialog 和表单组件。当前仍只支持 Claude；其他 Agent 各有自己的配置格式，不套用这一序列化方式。

## 数据与冲突规则

模板库保存在 Android 私有目录 `files/config-state/claude-profiles.json`，整份内容使用 Android Keystore AES-GCM 加密。它使用独立于配置备份的密钥别名和附加认证数据，避免两个存储用途混用。既有 0.4.0 备份的密钥别名和数据格式保持兼容。

每个模板包含稳定 id、独立 revision、名称、四个字段和更新时间。模板库本身也有 revision，用于防止两个编辑页面或管理器覆盖彼此的写入。写入使用文件锁与 AtomicFile；存储损坏、无法解密或出现符号链接路径时拒绝读取/覆盖，不按空库重建。

模板应用预览绑定两份身份：

1. 当前配置文件的完整字节 revision。
2. 所选模板的 id 和 revision。

确认应用时重新核对两者。当前配置被外部修改，或所选模板已编辑/删除，都会拒绝应用；其他无关模板的编辑不会使当前预览失效。所选模板的读取锁覆盖配置提交过程，保证 agentM 自身不会在提交中途替换它。

模板保存和删除不修改配置文件，所以可在终端运行期间管理模板。应用到配置文件仍要求关闭当前终端、等待软件管理结束。预览 token 保留 2 分钟，定时清理过期候选内容，最多同时保留 4 份。

名称限制为 1–80 个字符，禁止重名和控制字符；最多保存 32 个模板，加密文件上限 1 MiB。从现有文件复制时，冲突凭据、空字段或超出本适配器支持范围的字段组合会报错，避免静默改写认证语义。四个受管字段外的配置不会导入模板。

## 密钥处理

列表和编辑接口只返回 `hasSecret`、认证方式、非凭据字段和匹配状态，不回传存储的密钥。新输入仅在当前表单临时状态与原生提交路径存在，不进入 Zustand 持久状态、localStorage 或日志。

新增模板缺少密钥时不能借用当前配置或其他模板的密钥；编辑时只能保留被编辑模板自己的同类密钥。应用后 Claude 的原生配置仍包含它运行所需的明文凭据，权限为 0600；模板加密并不改变 Agent 读取自身凭据的能力。

## 验证结果

本轮在 emulator-5554 / Android 15 / x86_64 验证：

- TypeScript strict、Vite 生产构建和 Android APK 构建通过。
- 10 项 JVM 测试通过，桥策略用例扩展到模板读写与应用接口。
- 既有 `ClaudeConfigIntegrationTest` 继续通过，包含原文保留、0600、Keystore 备份恢复、配置冲突及路径检查。
- 新增 `ClaudeProfilesIntegrationTest` 通过，覆盖加密 CRUD、管理器重建后读取、密钥不回显、跨存储密钥隔离、捕获当前配置、模板/配置双 revision、删除不影响已配置文件、损坏库不被重建。
- 专门比较相同端点、相同模型、不同密钥的两个模板，确认只将实际匹配的那个标为一致。
- 实际 WebView 完成新增、编辑、预览并取消、删除临时测试模板。密钥不出现在预览或 localStorage；测试结束后真实 Claude 配置的 SHA-256 保持不变。
- Android Lint：0 errors / 23 warnings。

测试使用独立 fixture 目录和 `.invalid` 示例端点，未发送模型请求。没有宣称已验证提供商连通性、模型调用、arm64 真机、断电恢复或跨设备密钥迁移。
