# 应用版本与更新检查

版本：0.15.1，Android versionCode 22。设置页优先显示原生 `BuildConfig.VERSION_NAME` 返回的实际 APK 版本；浏览器预览使用同版本的 `APP_VERSION`。tag、Android 与前端版本由 `tools/release/check-version.mjs` 校验。

「设置 → 关于 → 检查更新」由 Android 后台线程请求 `https://api.github.com/repos/WEP-56/agentM/releases/latest`，使用 `tag_name` 比较数值版本，不按发布标题或字符串大小排序。仅接受公开正式版本；当前版本相同或更高时不提示降级，同版本的 alpha/beta/rc 可升级到正式版。

GitHub API 返回 403/429 时，回退读取 `https://github.com/WEP-56/agentM/releases/latest` 的跳转目标；只接受本仓库正式版本的 tag 地址。此路径不依赖 REST API 配额，不返回发布说明。网络错误、无公开 Release 和无更新分别提示，不将检查失败当成“已是最新版”。请求有连接/读取超时，元数据与展示说明有大小上限，不使用或内置 GitHub 凭据。

发现新版后显示版本与可用的发布说明，由用户点击「前往下载」打开对应发布页。GitHub 按钮打开 `https://github.com/WEP-56/agentM`。Android 使用原生 `ACTION_VIEW` 交给浏览器，避免 WebView 新窗口行为导致点击无效；原生接口只允许仓库、latest 或经过校验的正式 tag 页面，不接受任意 URL。

本功能不自动下载、安装 APK，不增加应用安装权限。版本比较、空发布、网络失败、异常 tag、来源限制与限流跳转回退由 `AppUpdatesTest` 覆盖；页面接口继续受主帧和精确 origin 策略约束。
