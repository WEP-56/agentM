agentM 首个公开版本：在 Android 上安装、配置和使用 AI 编程 Agent。

### 功能

- 无需 root 的 Ubuntu 用户态环境，内置 Linux 终端与开发工具安装引导。
- Claude Code、Codex、Pi 终端，以及 OpenCode TUI / WebUI、DSH WebUI。
- 四种 Agent 的原生提供商管理、模型设置和源码编辑，内置 Claude Official 与 OpenAI Official。
- 首页工作目录选择；新终端在所选项目目录启动。
- Android Keystore 加密提供商库与配置备份。

### 下载

安装 `agentM-0.14.0-universal.apk`，需要 Android 11+、arm64-v8a 或 x86_64。`SHA256SUMS.txt` 用于校验附件；`SIGNING-CERT.txt` 记录正式签名证书。`linux-runtime-sources.tar.gz` 是内置 Linux 组件的源码与构建资料，无需安装。

首次启动需联网安装 Ubuntu、工具和所需 Agent，并自行登录或配置提供商。

### 升级与已知限制

- 这是首个正式签名包，不能直接覆盖此前的 debug 安装。卸载会清除应用私有数据，请先备份项目与配置，再迁移安装。后续 Release 沿用此正式签名。
- Codex 的 proot 独立沙箱自检仍可能报告 `cannot establish app-server socket mount isolation`。
- 尚未覆盖完整 Agent 功能矩阵、arm64 真机、16 KB 页设备与各厂商长期后台场景。
