# agentM 0.15.1

- 新增「文件」分栏：浏览真实 Ubuntu 文件树，支持新建文件/文件夹、批量上传、名称搜索、重命名、移动、多选删除、另存为和分享；文件夹可导出 ZIP。
- 首次引导第一步加入通知、文件访问和后台运行权限入口；设置页重新引导保留已有环境、项目和配置。「环境」页仅保留存储统计。
- 「设置 → 关于」显示 APK 实际版本，按 GitHub 最新正式 Release 的 tag 检查更新，发现新版后可前往发布页下载；API 限流时回退到官方 latest 发布地址。GitHub 入口直接打开项目仓库。
- 修复 DSH 内置补丁因 CRLF/LF 转换导致的 SHA-256 校验失败，并加入构建回归检查。
- 修复 Android 应用私有目录别名导致文件页误报“Ubuntu 目录未就绪或已被替换”的问题，保留目录边界与符号链接校验。

上传和保存通过 Android 系统文件选择器授权；分享只向接收应用提供所选内容的临时读取权限。此版本沿用正式签名，可覆盖安装原正式版。
