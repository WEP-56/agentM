# agentM 0.15.0

- 首次引导第一步增加通知、文件访问和后台运行权限说明及授权入口，与设置页共用实际权限状态。
- 新增「文件」分栏，浏览真实 Ubuntu 文件树，支持新建文件/文件夹、批量上传、搜索、重命名、移动、多选删除、另存为及分享；文件夹可导出 ZIP。
- 上传、保存使用 Android 系统文件选择器授权，分享通过专用 FileProvider 提供临时只读授权。重名文件不会自动覆盖。
- 「环境」页移除文件树，仅保留存储统计。重新引导保留已有环境和用户数据。
- 修复 DSH 内置补丁因 CRLF/LF 转换造成的 SHA-256 校验失败，新增构建回归检查和明确错误提示。
