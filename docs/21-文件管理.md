# 文件管理与首次权限引导

0.15.0 在底部增加「文件」分栏。「环境」仅保留存储统计，旧的只读文件树和 `listStorage` 接口已移除。

## 权限

首次引导的第一步和设置页共用通知、文件访问、后台运行三项。授权为可选，拒绝后仍可进入工作台；从系统设置返回后刷新实际授权状态。重新引导会保留 Ubuntu、Agent、项目和配置。

Ubuntu 存放在应用私有目录，不需要 Android 的所有文件访问权限。上传使用系统 `ACTION_OPEN_DOCUMENT` 选择文件，读取授权只用于本次复制；另存为使用 `ACTION_CREATE_DOCUMENT` 取得所选目标的写入授权。用户取消选择时不开始复制。

分享先将所选内容复制到专用缓存，通过不导出的 `FileProvider` 和 `FLAG_GRANT_READ_URI_PERMISSION` 向接收应用授予临时读取权限。Provider 仅暴露 `cache/file-shares/`，不暴露 Ubuntu、工作区或整个应用目录。分享缓存保留供接收应用读取，下一次分享时清理超过 24 小时的旧缓存。

## Ubuntu 文件树

- `/` 是真实 Ubuntu 根文件系统；`/root`、`/workspace`、`/opt/agentm` 映射到与 proot 相同的主目录、工作区和受管软件目录。
- 支持显示隐藏文件、目录导航、按名称搜索当前目录及子目录、分页、新建文件/文件夹、批量上传、重命名、移动、多选删除。
- 上传和移动遇到同名项目时拒绝覆盖。上传先写临时文件，复制完成后发布；读取失败会清理临时文件。批量操作显示成功数量和失败信息，已经成功的项目不会伪装成回滚。
- 删除前显示所选路径并确认。删除目录会递归删除内容；删除符号链接仅删除链接本身。搜索和递归删除不跟随目录链接。
- 目录导航按 Ubuntu 语义解析相对、绝对符号链接，包括 `/bin` 等目录链接；不会把 Linux 链接当成 Android 宿主路径。
- 根目录、挂载点及其父目录不可删除/移动；`/opt/agentm` 只读。`/dev`、`/proc`、`/sys` 和 proot 内部 `.l2s` 不提供文件操作。其他系统文件可修改，删除前应确认用途。
- 文件夹另存为或分享时生成 ZIP，包含普通文件和空文件夹，不包含符号链接和虚拟设备目录。普通文件按原始字节传输。

目录每页最多 100 项，多选/上传每次最多 100 项。搜索达到扫描上限会明确提示缩小范围。目录扫描时其他 Agent 仍可能修改文件，遇到项目消失或冲突时刷新后重试。

## 手动验收

1. 在设置中重新引导，确认第一步出现三项权限；分别授权/取消，返回后确认状态更新，已有数据保留。
2. 打开「文件」，浏览工作区、主目录和 Ubuntu `/`；确认隐藏文件、目录链接和中文长文件名可正确显示。
3. 新建测试文件夹和文件；从 Android 选择多个文件上传。再次上传同名文件应报冲突且原内容不变。
4. 在当前目录搜索子目录中的文件；选择多项移动，验证目标目录，再重命名其中一项。
5. 将文件另存到 Downloads，分享到其他应用；将文件夹导出 ZIP 并检查解压后的内容。取消系统选择器不应创建 Ubuntu 文件。
6. 多选删除测试文件及文件夹，确认提示中的路径和结果；删除链接不应影响目标内容。
7. 环境页应只显示存储统计；DSH 安装问题和其他 Agent 行为由本次测试包继续验收。

自动检查包括 JVM 文件操作测试、前端类型检查、Release lint、APK 内 DSH 补丁摘要与签名检查。浏览器界面检查使用独立测试桩，不替代 Android SAF、分享面板或设备安装验收。

## 0.15.1 路径别名修复

用户已确认 0.15.0 的 DSH 安装与引导正常，文件分栏则报告“Ubuntu 目录未就绪或已被替换”。文件管理器现在从 Android 提供的可信 `filesDir` 解析一次真实路径，再拼接固定挂载目录；不会对可由 Ubuntu 修改的挂载目录整体做规范化，以免接受被替换的链接。目录校验使用 `toRealPath()`，统一 Android 与 Windows JVM 对路径别名的判定。新增回归覆盖带别名的应用目录、101 项文件分页及文件操作，同时验证挂载目录及其祖先被链接替换时仍拒绝访问。
