本机 `examples/DSHA` 和 `examples/cc-switch` 是历史精简快照，不是完整可构建工程；其中的 `REFERENCE.md` 可用于本地阅读。不要因未提交而重复删除本地文件，不要将它们强制添加回 Git。

需要完整参考时，在新的、已忽略的目录恢复：

```powershell
git clone https://github.com/DSH-APP/DSHA.git upstream-build/DSHA
git -C upstream-build/DSHA checkout --detach 70e37a7dbcae83b32fc92a8a37b33af88befc0e0
git clone https://github.com/farion1231/cc-switch.git upstream-build/cc-switch
git -C upstream-build/cc-switch checkout --detach 5ae6ad3888ba4543f6fad343c87656a97bd69da4
```

普通 APK 构建使用 agentM 已提交的运行时清单、代码及资产，不依赖 `examples/`。需要重新生成 OpenCode/DSH 安装清单时，`tools/prepare-web-agents.mjs` 从固定 DSHA 提交获取依赖锁，校验固定 SHA-256 并放入 `.cache/dsha-reference/`；`tools/prepare-dsh-overlays.py` 同样从固定提交补齐所需参考文件。

`git rm --cached` 移除当前索引中的文件，不会抹去既有提交里的历史副本。本次没有重写 Git 历史，也没有提交或推送删除；是否在首次公开前整理历史可另行决定。

产品实际复制或分发的第三方组件仍须保留来源和许可证，见 [Android 第三方说明](../android/third-party/README.md)。移除本地参考目录不改变这些组件的归属。
